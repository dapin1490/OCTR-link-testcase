# Cursor Instructions

1. `PRD.md`와 `TECHNICAL_SPEC.md`를 읽고 프로젝트의 의도를 파악할 것.
2. `manifest.json`은 Manifest V3 규격을 준수해서 작성할 것.
3. `content.js`에서 백준 페이지의 테스트 케이스를 파싱할 때, 입력과 출력이 쌍이 맞도록 (index 기준) 매칭할 것.
4. `lz-string.min.js` 라이브러리를 프로젝트에 포함하고, `content.js`에서 이를 호출해 데이터를 압축하는 로직을 구현할 것.
5. 버튼은 백준 사이트의 기존 메뉴 스타일과 어울리도록 디자인할 것.
6. 최종 결과물은 `online-cote-runner` 웹사이트의 상태 복원 로직과 완벽히 호환되어야 할 것.
